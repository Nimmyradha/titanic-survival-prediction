# Titanic Survival Prediction

   A beginner ML project predicting Titanic passenger survival using a Decision Tree Classifier.

   ## Steps
   - Data cleaning (handled missing Age, Embarked, dropped Cabin)
   - Feature encoding (Sex, Embarked converted to numeric)
   - Train/test split (80/20)
   - Model training with scikit-learn's DecisionTreeClassifier
   - Evaluation: ~80% accuracy on test data

   ## Tools
   Python, Pandas, Scikit-learn, Jupyter Notebook
